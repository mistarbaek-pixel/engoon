지도 API 연동 설정

현재 기본 지도는 Leaflet + OpenStreetMap 기반으로 즉시 작동하도록 오픈소스로 구현되어 있습니다. 카카오, 네이버, 구글 지도 API 키를 등록하여 고유 지도로 스위칭할 수 있습니다.

개발자 참고 가이드

입력한 API 키는 도메인 허용 설정이 완료된 승인 키여야 지도 로딩 시 CORS 또는 권한 오류가 발생하지 않습니다.

커스텀 도메인 연결 및 배포 안내

소유하고 계신 고유 도메인을 이 부동산 웹 앱에 연동하려면 아래 단계를 수행하세요.

1. 호스팅 플랫폼 선택 (무료 연동 추천)

Vercel, Netlify, Github Pages 또는 Cloudflare Pages에 이 코드(index.html)를 업로드합니다.

2. DNS 레코드 설정 (가비아 / 카페24 / 후이즈 등)

도메인 등록업체 DNS 관리 화면에서 CNAME 레코드를 지정합니다.

Type: CNAME | Name: @ 또는 www | Value: cname.vercel-dns.com

3. Map API 도메인 화이트리스트 등록

Kakao/Naver/Google 개발자 센터에서 발급한 API 키의 사용 도메인 목록에 구입하신 보유 도메인(예: https://yourdomain.com)을 추가해야 지도가 정상 표시됩니다.
